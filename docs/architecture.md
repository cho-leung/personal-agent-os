# Architecture

Personal Agent OS separates AI workflows into several layers.

## Human Layer

The human remains the final decision maker.

## Control Layer

Responsible for: - coordination; - ownership; - workflow rules; - state
management.

## Specialist Agents

Different agents handle bounded tasks.

Examples: - research; - learning; - operations.

## State Layer

Important information should be preserved through: - documents; -
artifacts; - structured records.

The goal is to make AI workflows more maintainable and transferable.
