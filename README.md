# Personal Agent OS

An experimental framework for organizing long-running AI agent
workflows.

## Overview

Personal Agent OS explores how humans can collaborate with multiple AI
agents over long periods of time.

The project focuses on: - agent workflow organization; - state
preservation; - human-in-the-loop control; - knowledge continuity.

## Motivation

AI assistants are powerful, but long-term workflows face challenges:

-   temporary conversation context;
-   unclear responsibilities;
-   lack of persistent state;
-   difficult knowledge transfer.

Core idea:

> Agents may change, but accumulated state and knowledge should remain.

## Core Principles

### Context != State

Conversation context is temporary. Important information should be
explicitly structured and preserved.

### Agent != Identity

An agent represents a role in a workflow. Changing an agent should not
mean losing project history.

### Ready != Authorized

The ability to perform an action does not automatically mean permission
to perform it.

### Prompt != Knowledge

Prompts define behavior. Knowledge comes from accumulated artifacts and
experience.
